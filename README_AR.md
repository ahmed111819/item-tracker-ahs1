# ماسح كوبونات Amazon.sa

يشغّل هذا المستودع بوت كوبونات واحدًا (Bot 1) على GitHub Actions. يحفظ سجل المنتجات وسجل إشعارات Telegram في PostgreSQL على السيرفر؛ السيرفر مخصص للتخزين ولا يشغّل فحص Amazon.

## التشغيل

- يرسل البوت تنبيه الكوبون/العرض الترويجي عند خصم 40% فأكثر.
- شغّل Workflow **Amazon.sa deal scanners** من GitHub Actions مع تفعيل `continuous` ليكرر دورة كاملة، ثم ينتظر 10 دقائق من انتهائها قبل الدورة التالية.
- أوقفه بإلغاء التشغيل الجاري في GitHub Actions.
- شغّل بوتًا واحدًا فقط. لا تشغّل نسخ Colab أو مسارات البوتات القديمة بالتزامن.

## إعداد PostgreSQL

1. راجع `DATABASE_SETUP_AR.md` لإعداد قاعدة البيانات والمستخدم والصلاحيات.
2. شغّل `postgres_schema.sql` مرة واحدة.
3. استورد ملف التتبع الحالي `amazon_deals_tracking_bot1.json` وسجل التنبيهات `amazon_deals_sent_registry.json` باستخدام `import_postgres.py`.
4. أضف سر GitHub Actions باسم `DATABASE_URL` يحتوي رابط PostgreSQL مع TLS؛ لا تضع كلمات المرور أو ملفات JSON في المستودع.
5. أبقِ `TELEGRAM_BOT_TOKEN` و`TELEGRAM_CHAT_ID` في GitHub Secrets.

البوت يرفض بدء الفحص إذا لم تكن حالة Bot 1 وسجل التنبيهات مستوردين؛ هذا يمنع إنشاء تاريخ فارغ أو الكتابة فوق الحالة القديمة. ملف سجل التنبيهات وحده لا يحتوي سجل المنتجات، ولذلك يلزم ملف التتبع أيضًا.

## سعة التخزين

حالة التتبع مضغوطة ومخزنة في صف واحد لكل بوت؛ كل حفظ يستبدل الصف نفسه بدل إنشاء ملف جديد. نسخة Bot 1 المضغوطة كانت نحو 8.5 MB في تشغيل سابق. يلزم توفير مساحة إضافية لـ PostgreSQL WAL والنسخ الاحتياطية والتنظيف التلقائي.

## متطلبات الاتصال

يجب أن يصل GitHub Actions إلى PostgreSQL عبر TLS ومستخدم محدود الصلاحيات. لا تفتح قاعدة البيانات دون كلمة مرور أو دون TLS. راجع مزود السيرفر لإعداد جدار الحماية والوصول الآمن.
