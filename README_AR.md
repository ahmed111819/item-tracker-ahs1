# item-tracker-ahs1 — ماسح عروض Amazon.sa

هذا المستودع عام؛ لا تضف إليه رموز تيليجرام أو مفاتيح Google أو ملفات التتبع. تم إيقاف سير عمل Amazon Yalla في GitHub لأن تشغيله مستضاف خارجيًا.

## البوتات الثلاثة

يشغّل سير العمل Bot 1 وBot 2 وBot 3 بالتوازي على عامل GitHub Actions واحد. لكل بوت روابطه وملف تتبعه المستقل، ويشتركون في سجل التنبيهات على Google Drive. داخل كل رابط يعمل عاملان للصفحات، مع حد أقصى 10 صفحات نشطة لكل بوت.

- ابدأ من Actions → Amazon.sa deal scanners → Run workflow، واترك خيار `continuous` مفعّلًا للاستمرار.
- ينتهي كل تشغيل خلال 3 ساعات كحد أقصى، ثم ينتظر 10 دقائق ويبدأ تشغيل GitHub جديد تلقائيًا. عند تعطل أحد الماسحات، يعيد GitHub محاولة تشغيله حتى ثلاث مرات، ثم ينتقل إلى تشغيل جديد.
- يُحفظ التقدم في Drive لاستئنافه في التشغيل التالي. لإيقاف السلسلة، ألغِ التشغيل الجاري من Actions.
- لمرة واحدة فقط، ألغِ خيار `continuous`.
- يحتاج مجلد Drive إلى ملفات التتبع الثلاثة: `amazon_deals_tracking_bot1.json` و`amazon_deals_tracking_bot2.json` و`amazon_deals_tracking_bot3.json`، إضافة إلى `amazon_deals_sent_registry.json`.
- لا يحتاج الماسح إلى `state.json` أو مجلد جلسة Amazon.

أوقف نسخ Colab للبوتات الثلاثة عند نقلها للتشغيل في GitHub؛ لا تشغّل أي نسخة Colab بالتزامن مع نسخة GitHub على ملف التتبع نفسه.
